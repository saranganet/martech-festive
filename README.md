# MarTech Panthers - Ganesh Chaturthi Special Landing Page

A promotional festive offer landing page for **MarTech Panthers**, featuring:

- **Theme**: Ganesh Chaturthi Special — "Remove Obstacles. Unlock Growth."
- **Offer**: Up to 50% off (capped at ₹45,000) on Sales Enablement & Automation implementation.
- **Aesthetic**: Divine festive palette with warm ivory background, rich emerald conversion card, terracotta CTAs, gold serif typography, and 3D Lord Ganesha hero artwork.
- **Interactive Features**:
  - Live project savings calculator slider with instant discount and cap calculation.
  - Interactive pricing tier cards synced with calculator.
  - Lead capture form with celebratory confetti animation and modal confirmation.
  - Strategy session booking modal.
  - Fully responsive across desktop, tablet, and mobile devices.

## Tech Stack
- HTML5 (Semantic structure, modern typography)
- Vanilla CSS3 (Custom design system, micro-animations, glassmorphism, responsive grid & flexbox)
- Vanilla JavaScript (Dynamic savings calculation, form handlers, confetti, interactive modals)

## Getting Started
To view locally:
```bash
# Using Python
python3 -m http.server 3000

# Or using Node
npx serve
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
